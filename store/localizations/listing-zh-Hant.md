## Description (597/4000)
一款快速而私密的 macOS 純文字編輯器。既適合習慣 Windows 記事本的人，也適合想要比文字編輯更好用的標籤與還原功能的人。

沒有 AI。沒有帳號。不必用雲端。只有文字。

自動還原工作階段
就算帶著未儲存的筆記關閉應用程式，下次啟動（包括重新開機後）也會原樣回來。可在設定中選擇每次啟動是接續上次或重新開始。

多標籤
在一個視窗裡處理多個文件。拖曳重新排序、Ctrl-Tab 切換，未儲存的標籤會帶 * 標記。

編碼
以 UTF-8、UTF-8（BOM）、EUC-KR、UTF-16（LE/BE）開啟與儲存。可在狀態列用另一種編碼重新開啟或轉換，遇到無法表示的字元會明確提示。中文與韓文輸入在組字過程中也不會遺失。

拼字檢查與自動修正
使用 macOS 系統詞典，不連網。自動修正為選用，程式碼與記錄檔副檔名可關閉檢查。

選用預覽
.md 與 .html 支援並排或全螢幕預覽。不執行指令碼。遠端圖片與 CSS 只有在該標籤允許後才載入。

其他
• 行內尋找與取代 — 相符數量、循環尋找、區分大小寫
• Markdown、JSON、XML、HTML、記錄檔的語法標示
• 列印與版面設定、跳至行、插入時間/日期、自動換行、縮放
• 多視窗、淺色/深色模式、介面支援 16 種語言

隱私
完全在沙箱中執行，沒有廣告，不收集任何資料。僅在預覽中允許遠端圖片的標籤才會連網。

## What's New — v1.2.9 (333/4000)
修正了開啟與關閉檔案的問題。

• 從 Finder 開啟文件不再為它加上 macOS 隔離屬性。以前即使沒有寫入，只是讀取也會加上該屬性，之後每次開啟這個檔案 — 無論用本應用程式或其他應用程式 — 都會出現檢查對話框。現在開啟只會讀取，只有儲存時才寫入檔案。

• 打不開的檔案現在能開啟了。若某個標籤在啟動時無法還原，再次開啟該檔案只會切到空白標籤而不讀取內容。

• 透過大小寫不同的路徑或符號連結開啟同一檔案時，不再產生兩個互相覆蓋編輯的標籤。

• 在無法讀取原文的標籤中輸入，不再略過取代原檔案前的警告。

• 關閉最後一個標籤會關閉視窗。以前看起來像什麼都沒發生。

• 開啟檔案時不再留下一個空的「未命名」標籤。

• 儲存失敗時會說明真正的原因。
