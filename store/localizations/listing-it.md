## Description (1653/4000)
Un editor di testo semplice, rapido e riservato per macOS. Per chi arriva dal Blocco note di Windows e per chi vuole le schede e il ripristino che TextEdit non offre.

Nessuna IA. Nessun account. Nessun cloud obbligatorio. Solo testo.

Ripristino automatico della sessione
Chiudi l'app con le schede aperte, comprese le note non salvate: al lancio successivo, anche dopo un riavvio, tutto torna com'era. Nelle impostazioni scegli se ogni avvio riprende la sessione precedente o ne inizia una nuova.

Più schede
Lavora su più documenti in una finestra. Riordina trascinando, cambia con Ctrl-Tab; le schede non salvate mostrano un *.

Codifiche
Apre e salva in UTF-8, UTF-8 con BOM, EUC-KR e UTF-16 (LE/BE). Dalla barra di stato puoi riaprire con un'altra codifica o convertire il contenuto, con un avviso chiaro se un carattere non è rappresentabile.

Ortografia e correzione
Usa i dizionari di sistema di macOS, senza rete. La correzione automatica è opzionale e il controllo si può disattivare per le estensioni di codice o di log.

Anteprima opzionale
Anteprima di .md e .html affiancata o a schermo intero. Gli script non vengono eseguiti. Immagini e CSS remoti si caricano solo dopo il tuo consenso in quella scheda.

Inoltre
• Trova e sostituisci in linea, con conteggio e distinzione tra maiuscole
• Evidenziazione di Markdown, JSON, XML, HTML e log
• Stampa, vai alla riga, inserisci ora e data, ritorno a capo, zoom
• Più finestre, modo chiaro e scuro, interfaccia in 16 lingue

Privacy
Gira in un sandbox completo, senza pubblicità, e non raccoglie alcun dato. La rete si usa solo nelle schede in cui consenti le immagini remote nell'anteprima.

## What's New — v1.2.9 (1093/4000)
Correzioni all'apertura e alla chiusura dei file.

• Aprire un documento dal Finder non aggiunge più l'attributo di quarantena di macOS. Prima bastava leggerlo per aggiungerlo anche senza scrivere nulla, e in seguito il Finder chiedeva di verificare il file a ogni apertura, con questa o con qualsiasi altra app. Ora l'apertura si limita a leggere; il file viene scritto solo al salvataggio.

• Un file che si rifiutava di aprirsi ora si apre. Se una scheda non poteva essere ripristinata all'avvio, riaprire quel file passava soltanto alla scheda vuota senza leggerlo.

• Lo stesso file raggiunto da un percorso diverso — variante di maiuscole o collegamento simbolico — non si apre più come due schede che si sovrascrivono.

• Digitare in una scheda il cui file non è stato letto non salta più l'avviso prima di sostituire l'originale.

• Chiudere l'ultima scheda chiude la finestra. Prima sembrava che non accadesse nulla.

• Aprire un file non lascia più una scheda "Senza titolo" vuota accanto.

• Gli errori di salvataggio indicano la causa reale invece di chiedere sempre una posizione.
