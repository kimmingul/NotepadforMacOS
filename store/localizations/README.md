# App Store localizations

Store copy per language, as uploaded to App Store Connect for v1.2.9. The app ships 16 UI
languages; these files are the store page in the same set. `en-US` remains the primary
locale and lives in `../listing-en.md`.

App name stays `Notepad Classic` in every locale — only the subtitle, promotional text,
keywords, description and release notes are localized. Screenshots are the same two images
from `../screenshots/`, uploaded per locale because App Store Connect requires a set for
each language.
