## Description (1675/4000)
Быстрый и приватный редактор простого текста для macOS. Для тех, кто привык к Блокноту в Windows, и для тех, кому нужны вкладки и восстановление, которых нет в TextEdit.

Без ИИ. Без аккаунта. Без обязательного облака. Только текст.

Автоматическое восстановление сессии
Закройте приложение с открытыми вкладками, включая несохранённые заметки: при следующем запуске, в том числе после перезагрузки, всё вернётся как было. В настройках можно выбрать, продолжать прошлую сессию или начинать новую.

Несколько вкладок
Работайте с несколькими документами в одном окне. Порядок меняется перетаскиванием, переключение — Ctrl-Tab, несохранённые вкладки помечены звёздочкой.

Кодировки
Открывает и сохраняет в UTF-8, UTF-8 с BOM, EUC-KR и UTF-16 (LE/BE). Из строки состояния можно открыть заново в другой кодировке или преобразовать содержимое, а о непредставимых символах приложение предупреждает прямо.

Проверка орфографии
Использует системные словари macOS и не обращается к сети. Автозамена по желанию, а для расширений кода и журналов проверку можно отключить.

Предпросмотр по желанию
Предпросмотр .md и .html рядом или на весь экран. Скрипты не выполняются. Удалённые изображения и CSS загружаются только после разрешения в этой вкладке.

Кроме того
• Поиск и замена в строке, счёт совпадений, учёт регистра
• Подсветка Markdown, JSON, XML, HTML и журналов
• Печать, переход к строке, вставка времени и даты, перенос строк, масштаб
• Несколько окон, светлая и тёмная тема, интерфейс на 16 языках

Приватность
Работает в полной песочнице, без рекламы, и не собирает никаких данных. Сеть используется только во вкладках, где вы разрешили удалённые изображения в предпросмотре.

## What's New — v1.2.9 (1083/4000)
Исправления при открытии и закрытии файлов.

• Открытие документа из Finder больше не добавляет ему атрибут карантина macOS. Раньше его добавляло само чтение, хотя ничего не записывалось, и после этого Finder предлагал проверить файл при каждом открытии — и в этом приложении, и в любом другом. Теперь открытие только читает; файл записывается лишь при сохранении.

• Файл, который отказывался открываться, открывается. Если вкладку не удавалось восстановить при запуске, повторное открытие файла лишь переключало на пустую вкладку, не читая его.

• Один и тот же файл, найденный по другому пути — с другим регистром или через символическую ссылку, — больше не открывается двумя вкладками, затирающими правки друг друга.

• Ввод текста во вкладке, файл которой не удалось прочитать, больше не пропускает предупреждение перед заменой оригинала.

• Закрытие последней вкладки закрывает окно. Раньше казалось, что ничего не произошло.

• При открытии файла рядом не остаётся пустая вкладка «Без названия».

• Ошибки сохранения сообщают настоящую причину вместо запроса места каждый раз.
