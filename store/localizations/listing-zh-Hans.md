## Description (588/4000)
一款快速而私密的 macOS 纯文本编辑器。既适合习惯 Windows 记事本的人，也适合想要比文本编辑更好用的标签与恢复功能的人。

没有 AI。没有账户。不必用云。只有文本。

自动恢复会话
即使带着未保存的笔记关闭应用，下次启动（包括重启之后）也会原样回来。可以在设置中选择每次启动是继续上次会话还是新建。

多标签
在一个窗口里处理多个文档。拖动重排、Ctrl-Tab 切换，未保存的标签会带 * 标记。

编码
以 UTF-8、UTF-8（BOM）、EUC-KR、UTF-16（LE/BE）打开和保存。可在状态栏用另一种编码重新打开或转换，遇到无法表示的字符会明确提示。中文与韩文输入在组字过程中也不会丢失。

拼写检查与自动更正
使用 macOS 系统词典，不联网。自动更正可选，代码与日志扩展名可关闭检查。

可选预览
.md 与 .html 支持并排或全屏预览。不执行脚本。远程图片与 CSS 只有在该标签中允许后才加载。

其他
• 内联查找与替换 — 匹配计数、循环查找、区分大小写
• Markdown、JSON、XML、HTML、日志的语法高亮
• 打印与页面设置、跳转到行、插入时间/日期、自动换行、缩放
• 多窗口、浅色/深色模式、界面支持 16 种语言

隐私
完全在沙盒中运行，没有广告，不收集任何数据。仅在预览中允许远程图片的标签里才会联网。

## What's New — v1.2.9 (330/4000)
修复了打开和关闭文件的问题。

• 从 Finder 打开文档不再给它加上 macOS 隔离属性。以前即使什么都没写，仅仅读取也会加上该属性，之后每次打开这个文件 — 无论用本应用还是别的应用 — 都会弹出检查对话框。现在打开只读取，只有保存时才写入文件。

• 打不开的文件现在能打开了。如果某个标签在启动时无法恢复，再次打开该文件只会切到空标签而不读取内容。

• 通过大小写不同的路径或符号链接打开同一文件时，不再产生两个互相覆盖编辑的标签。

• 在无法读取原文的标签中输入，不再跳过替换原文件前的警告。

• 关闭最后一个标签会关闭窗口。以前看起来像什么都没发生。

• 打开文件时不再留下一个空的“未命名”标签。

• 保存失败时会说明真正的原因。
