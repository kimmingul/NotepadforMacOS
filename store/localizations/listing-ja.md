## Description (799/4000)
速くて私的な macOS 向けプレーンテキストエディタです。Windows のメモ帳に慣れた方にも、テキストエディットよりタブと復元が欲しい方にも向いています。

AI なし。アカウントなし。クラウド必須なし。あるのはテキストだけです。

セッションの自動復元
未保存のメモを含めたタブをそのままにして終了しても、次回起動時（再起動後も）そのまま戻ります。起動ごとに前回の続きか新規かを設定で選べます。

複数タブ
ひとつのウインドウで複数の文書を扱います。ドラッグで並べ替え、Ctrl-Tab で切り替え、未保存のタブには * が付きます。

エンコーディング
UTF-8、UTF-8（BOM）、EUC-KR、UTF-16（LE/BE）で開いて保存します。ステータスバーから別のエンコーディングで開き直したり変換したりでき、表現できない文字があるときは明示的に知らせます。日本語や韓国語の入力は変換中でも失われません。

スペルチェックと自動修正
macOS のシステム辞書を使い、ネットワークは使いません。自動修正は任意で、コードやログの拡張子では無効にできます。

任意のプレビュー
.md と .html を横または全画面でプレビューします。スクリプトは実行しません。リモート画像と CSS はそのタブで許可したあとだけ読み込みます。

そのほか
• インラインの検索と置換 — 一致件数、折り返し検索、大文字小文字の区別
• Markdown、JSON、XML、HTML、ログのソースハイライト
• 印刷とページ設定、行へ移動、時刻/日付の挿入、行の折り返し、拡大縮小
• 複数ウインドウ、ライト/ダークモード、UI は 16 言語

プライバシー
完全なサンドボックスで動作し、広告はなく、データを一切収集しません。ネットワークはプレビューでリモート画像を許可したタブでのみ使われます。
