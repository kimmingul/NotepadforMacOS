## 부제 (30)
AI 없음 · 탭 · 세션 복원

## 프로모션 텍스트 (170)
AI·계정·클라우드 없는 Mac 플레인 텍스트 메모장. 멀티 탭, 미저장 세션 복원, 로컬 맞춤법 검사, UTF-8·EUC-KR·UTF-16 인코딩. 파일은 Mac에만 남습니다.

## 설명 (4000)

Notepad Classic(스토어 이름)은 빠르고 사적인 macOS 플레인 텍스트 편집기입니다. Windows 11 기본 메모장에 익숙한 분도, TextEdit보다 탭·복원을 원하는 분도 쓸 수 있습니다.

위지윅 없음. AI 없음. 계정 없음. 클라우드 필수 아님. 오직 텍스트 — 열고, 쓰고, 다음에도 그대로 있을 거라 믿으면 됩니다. Markdown과 HTML은 원할 때만 미리보기를 엽니다. 원문은 플레인 텍스트입니다.

세션 자동 복원
탭을 열어둔 채 — 저장하지 않은 메모까지 — 앱을 종료해도, 다음 실행 때(재부팅 후에도) 떠난 그대로 모두 복원됩니다. 설정에서 매 실행 시 "이전 세션 계속"과 "새 세션 시작" 중 선택할 수 있습니다.

멀티 탭
한 창에서 여러 문서를 다룹니다. 드래그로 탭 순서를 바꾸고, Ctrl-Tab으로 순환하며, 저장하지 않은 탭에는 * 표시가 붙습니다.

한국어(그리고 레거시) 텍스트에 강함
UTF-8, UTF-8(BOM), EUC-KR, UTF-16(LE/BE)로 열고 저장합니다. 상태바에서 다른 인코딩으로 다시 열거나 현재 내용을 변환할 수 있고, 표현할 수 없는 문자가 있으면 분명하게 경고합니다. 한글 등 CJK 입력은 조합 중 손실 없이 안전하게 커밋됩니다.

맞춤법과 자동 수정
macOS 시스템 사전으로 맞춤법 검사(기본 켜짐). 자동 수정은 선택. 코드·로그 확장자는 설정에서 검사를 끌 수 있습니다. 맞춤법 검사는 네트워크를 쓰지 않습니다.

선택 미리보기
.md / .html 사이드 또는 전체화면 미리보기. 스크립트는 실행하지 않습니다. 원격 이미지·CSS는 그 탭에서 허용한 뒤에만 불러옵니다. 저장된 파일은 기본 브라우저에서 열 수 있습니다.

필요한 건 다 있습니다
• 비모달 인라인 찾기/바꾸기 — 일치 개수, 둘러 찾기, 대소문자 옵션
• Markdown, JSON, XML, HTML, 로그 소스 하이라이트
• 인쇄 및 페이지 설정
• 줄로 이동, 시간/날짜 삽입, 자동 줄바꿈 토글, 확대/축소
• 시작 안내 · 새로운 기능 안내
• 다중 창
• 라이트/다크 모드

설계부터 프라이버시 우선
Notepad는 완전한 샌드박스에서 실행되며, 광고가 없고, 어떤 데이터도 수집하지 않습니다. 네트워크는 Markdown/HTML 미리보기에서 원격 이미지·CSS를 허용한 탭에서만 사용합니다. 파일은 오롯이 당신의 Mac에 남습니다.
