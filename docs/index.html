What's new in v1.2.11

Opening a file from Finder — whether Notepad is running or not — gives you one window with the file as a tab. Release notes

  • Launching Notepad by opening a document no longer shows extra empty windows beside it.
  • Opening a file while Notepad is running adds a tab to the window you are using.
  • The same file is never open in two windows: Notepad switches to the window that already has it.
  • Install from the signed .pkg: the installed app carries no quarantine record.

A notepad, not another notes cloud.

No WYSIWYG. No AI rewrite. Markdown, HTML, JSON, XML, and logs are first-class files—with highlight. Preview only when you ask.

Session restore.

Unsaved tabs come back after quit, restart, even reboot. Or start fresh from Settings—your choice.

Real tabs.

Several documents in one window. Drag to reorder, Ctrl-Tab to cycle, asterisk on dirty files.

Private by design.

Sandboxed. No ads. No tracking. No account. Network only if you allow remote images or CSS in a preview tab.

Local spell check.

System dictionary underlines and suggestions. Optional autocorrect. Turn off for code and log extensions.

Highlight the source.

Markdown, HTML, JSON, XML, and logs get syntax highlight in the editor. .txt stays plain text.

Preview when you want.

Optional side or full-screen preview for .md and .html. Scripts never run. Open in your browser if you need the real page.

Light enough to keep. Careful enough not to lose work.

Plain text only—by intention. Session restore remembers unsaved buffers. If a restored file can’t be read from disk, we never silently overwrite it with empty content.

Your files stay on your Mac.

No ads, no trackers, no data collection. Network only if you allow remote images or CSS in a Markdown or HTML preview tab. Open only the files you choose, inside the App Sandbox. Read the privacy policy.
