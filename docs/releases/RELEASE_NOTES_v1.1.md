# Notepad for macOS v1.1.0

Windows 11 **기본 메모장** 수준에 맞춘 플레인 텍스트 개선 릴리즈입니다.  
AI · Markdown · 표 · 이미지는 **의도적으로 포함하지 않습니다**.

A plain-text-focused update aiming at **Windows 11 basic Notepad** parity.  
**No** AI, Markdown, tables, or images.

**Download:** [Notepad-v1.1.0.dmg](https://github.com/kimmingul/NotepadforMacOS/releases/tag/v1.1.0) (Developer ID signed · notarized)  
**Site:** https://kimmingul.github.io/NotepadforMacOS/

## English

### Highlights
- **Spell check** (on by default) via the macOS system dictionary — underlines and suggestions, no network.
- **Autocorrect** (off by default), independent toggle in Settings and the Edit menu.
- **Disable spelling by extension** (e.g. `log`, `json`, `swift`) so code/logs stay quiet.
- **Welcome** on first launch; **What's New** when upgrading (reopen from Help). Existing v1.0 installs are migrated to see What's New (not a false first-run Welcome).
- **Status bar polish**: click line/col to Go to Line; clearer encoding (reopen vs convert) menus.
- **Font settings** captions clarify zoom vs default size (reset = 14 pt).
- Unit tests for spelling preference parsing and onboarding rules.

### Non-goals (unchanged)
- No AI rewrite/summarize/write
- No rich formatting / Markdown preview / tables / images
- No accounts, telemetry, or network features

### Install
1. Open the DMG and drag **Notepad** into **Applications**.
2. Launch. (Notarized builds open without Gatekeeper workarounds.)

Requires Apple Silicon (arm64).

### Version
- Marketing version: **1.1.0**
- Build: **2**

## 한국어

### 주요 기능
- **맞춤법 검사**(기본 켜짐) — macOS 시스템 사전, 밑줄·제안, 네트워크 없음.
- **자동 수정**(기본 꺼짐) — 설정 및 편집 메뉴에서 독립 토글.
- **확장자별 비활성** (`log`, `json`, `swift` 등) — 코드/로그에서는 검사 생략.
- **시작 안내**(첫 실행), **새로운 기능**(버전 업그레이드) — 도움말에서 다시 열기. v1.0 사용자는 Welcome이 아니라 What's New가 표시되도록 마이그레이션됩니다.
- **상태 표시줄**: 줄/열 클릭 → 줄로 이동, 인코딩 메뉴(다시 열기 / 변환) 구분.
- **글꼴 설정** 설명 보강(확대/축소와 기본 크기, 재설정 = 14 pt).
- 맞춤법·온보딩 단위 테스트 추가.

### 의도적 비목표
- AI 재작성/요약/생성 없음
- 서식 · Markdown 미리보기 · 표 · 이미지 없음
- 계정 · 텔레메트리 · 네트워크 기능 없음

### 설치
1. DMG를 열고 **Notepad**를 **Applications**로 드래그합니다.
2. 실행합니다. (공증 빌드는 Gatekeeper 우회 없이 실행됩니다.)

Apple Silicon(arm64) 필요.

### 버전
- 표시 버전: **1.1.0**
- 빌드: **2**
