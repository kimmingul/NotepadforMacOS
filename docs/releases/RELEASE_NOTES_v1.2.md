# Notepad for macOS v1.2.0

Optional Markdown and HTML preview on top of the same plain-text editor.  
Not a WYSIWYG. Source stays `NSTextView`. Scripts never run.

플레인 텍스트 편집기는 그대로 두고, `.md` / `.html`에서만 원할 때 미리보기를 엽니다.  
위지윅이 아닙니다. 스크립트는 실행하지 않습니다.

## English

### Highlights
- **Preview** for `.md` / `.markdown` and `.html` / `.htm`: side pane or full screen. Off by default.
- **Source highlight** for Markdown, JSON, XML, HTML, and logs. `.txt` stays plain.
- **Safe HTML preview**: scripts, `javascript:` / `data:` URLs, and event handlers are stripped. Remote images and CSS load only after you allow them **for that tab**.
- **Local images** after folder access; paths that escape the document folder (`..`) are refused.
- **Open in default browser** from the preview header (saved files).
- Preview toggle (`⌘⌥P`), full screen (`⌘⌥↩`), status-bar **Preview** / **Hide Preview**. The tab-bar icon stays visible next to **+** and appearance while the pane is open.

### Non-goals (unchanged)
- No AI rewrite/summarize/write
- No Typora-style inline editing, math, or Mermaid
- No accounts, telemetry, or analytics
- No network unless you allow remote images/CSS in a preview tab

### Install
1. Open the DMG and drag **Notepad** into **Applications**.
2. Launch. (Notarized builds open without Gatekeeper workarounds.)

Requires Apple Silicon (arm64).

- Marketing version: **1.2.0**

## 한국어

### 주요 기능
- **미리보기** — `.md` / `.markdown`, `.html` / `.htm`. 사이드 또는 전체화면. 기본은 꺼짐.
- **소스 하이라이트** — Markdown, JSON, XML, HTML, 로그. `.txt`는 플레인.
- **안전한 HTML 미리보기** — 스크립트, `javascript:` / `data:` URL, 이벤트 핸들러 제거. 원격 이미지·CSS는 **그 탭에서 허용한 뒤**에만.
- **로컬 이미지** — 폴더 접근 허용 후. 문서 폴더 밖(`..`)은 거부.
- **기본 브라우저에서 열기** — 미리보기 헤더(저장된 파일).
- 토글 `⌘⌥P`, 전체화면 `⌘⌥↩`, 상태바 **미리보기** / **미리보기 숨기기**. 패널이 열려도 탭바 `+` / 미리보기 / 모양 아이콘이 그대로 보입니다.

### 의도적 비목표
- AI 재작성/요약/생성 없음
- 인라인 위지윅 · 수식 · Mermaid 없음
- 계정 · 텔레메트리 · 분석 없음
- 미리보기에서 원격 이미지/CSS를 허용하기 전에는 네트워크 없음

### 설치
1. DMG를 열고 **Notepad**를 **Applications**로 드래그합니다.
2. 실행합니다. (공증 빌드는 Gatekeeper 우회 없이 실행됩니다.)

Apple Silicon(arm64) 필요.

### 버전
- 표시 버전: **1.2.0**
- 빌드: **3**
