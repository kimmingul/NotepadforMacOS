# Notepad for macOS v1.2.4

Finder **Open With** / **Always Open With** fix. Install this **notarized Developer ID DMG** — the app itself is stapled.

Finder ‘다음으로 열기’ 수정. **공증 DMG**로 설치하세요. 앱에도 티켓이 붙어 있습니다.

**Download:** [Notepad-v1.2.4.dmg](https://github.com/kimmingul/NotepadforMacOS/releases/tag/v1.2.4)

### Fix
- Default-handler / Open With no longer quits before the file is delivered.
- The `.app` inside the DMG carries its own notarization ticket (not only the disk image).

### Install on another Mac
1. Delete the old Notepad from Applications.
2. Download the DMG above (do not reuse a cached 1.2.3 file).
3. Drag **Notepad** into **Applications**.
4. Launch Notepad once, then double-click a `.md` / `.txt`.
