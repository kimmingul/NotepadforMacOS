# Notepad for macOS v1.2.3

16 UI languages. Install from this **notarized Developer ID DMG** on other Macs — do not copy a Debug build.

UI 16개 언어. **다른 Mac에는 이 공증 DMG만** 설치하세요. Debug 빌드를 복사하면 Gatekeeper가 막습니다.

**Download:** [Notepad-v1.2.3.dmg](https://github.com/kimmingul/NotepadforMacOS/releases/tag/v1.2.3) (Developer ID signed · notarized)  
**Site:** https://kimmingul.github.io/NotepadforMacOS/

---

## English

### Languages
- Settings → Language. Default follows this Mac.
- English, Korean, Japanese, Chinese (Simplified and Traditional), Spanish, French, German, Portuguese (Brazil), Italian, Russian, Vietnamese, Indonesian, Thai, Polish, Dutch.
- Language names stay in their own script.
- Changing the language relaunches Notepad.

### Install on another Mac
1. Download the DMG from the link above (not a copy of Notepad.app from AirDrop/USB Debug).
2. Open the DMG and drag **Notepad** into **Applications**.
3. Launch Notepad once, then open your files.

Requires Apple Silicon (arm64).

### Version
- Marketing version: **1.2.3**
- Build: **8**

## 한국어

### 언어
- 설정 → 언어. 기본값은 이 Mac의 언어입니다.
- 영어, 한국어, 일본어, 중국어(간체/번체), 스페인어, 프랑스어, 독일어, 포르투갈어(브라질), 이탈리아어, 러시아어, 베트남어, 인도네시아어, 태국어, 폴란드어, 네덜란드어.
- 목록은 각 언어 고유 표기입니다.
- 언어를 바꾸면 Notepad가 다시 실행됩니다.

### 다른 Mac에 설치
1. 위 DMG를 받습니다. Debug 앱이나 AirDrop으로 복사한 `.app`은 쓰지 마세요.
2. DMG를 열고 **Notepad**를 **응용 프로그램**으로 드래그합니다.
3. Notepad를 한 번 실행한 뒤 파일을 엽니다.

Apple Silicon(arm64) 필요.

### 버전
- 표시 버전: **1.2.3**
- 빌드: **8**
